# Paper build

No `pdflatex` is installed on the development machine (only the `texlive-binaries`
stub), so this directory is an **Overleaf-ready bundle**, not a locally built PDF.

## Build

Upload the whole `paper/` directory to Overleaf, set the compiler to **pdfLaTeX**
and the main document to `main.tex`. `IEEEtran.cls` is vendored here so the
project needs no external class.

Locally, if you install TeX Live (`sudo apt install texlive-latex-recommended
texlive-latex-extra texlive-science`):

```bash
cd paper
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Files

| file | role |
|---|---|
| `main.tex` | the paper |
| `refs.bib` | bibliography — every entry verified against a primary source |

| `IEEEtran.cls` | vendored IEEE conference class |
| `figures/` | **generated** by `scripts/plot_results.py` and `scripts/render_scene.py` |

## Page limit — read this before submitting

The target is **4 pages including references**. The count is **unverified**: no
LaTeX toolchain is installed on the development machine (conda's `texlive-core`
ships binaries and fonts but no macro packages, and a full install needs sudo),
so this was never compiled locally.

The paper was rewritten around the 4-page target: **4 figures, 1 table, ~3.3k
words of body text**. Two tables (environment spec, reward terms), the geometry
schematic and the standalone rate-limiter figure were folded into prose, and the
CasADi and hybrid material was merged into a single comparison section.

By estimate this lands at **~4.2–4.4 pages** — close, but likely a little long.
It cannot be checked without compiling. If the first Overleaf build overflows,
cut in this order:

1. **`fig_eval.pdf`** → keep panel (c) only, as a single-column figure; the
   $d(t)$/$\theta(t)$ conclusions are already stated numerically in the text
   (~3 column-inches).
2. **Sec. II-B** → drop the "inverse fruit placement" rationale paragraph,
   keeping the one-sentence description (~80 words).
3. **Sec. V-A** → drop the second paragraph of the negative control, keeping the
   observability argument (~90 words).
4. **`fig1_training.pdf`** → shrink to a single panel (success rate only); the
   return curve is described in the text (~1.5 column-inches).

Unused figures still generated by `plot_results.py` (`fig_geometry.pdf`,
`fig3_smooth_control.pdf`) are kept for slides and for the repo, and are simply
not referenced by `main.tex`.
